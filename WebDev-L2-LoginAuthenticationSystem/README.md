# Login Authentication System

## 📌 Overview

This Login Authentication System was created as part of the **Oasis Infobyte Web Development & Designing Internship – Level 2**.

The project provides a simple authentication system where users can register, log in, access a protected dashboard, and log out.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## ✨ Features

- User registration
- Username/email validation
- Password validation
- Minimum 8-character password requirement
- At least one number required in the password
- Duplicate user checking
- User login
- Incorrect credential validation
- Protected dashboard
- Logout functionality
- Session handling
- Basic form validation
- Secure password handling
- Responsive and user-friendly interface
