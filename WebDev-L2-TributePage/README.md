# Tribute Page

## 📌 Overview

This Tribute Page was created as part of the Oasis Infobyte Web Development & Designing Internship – Level 2.

The project is designed to present information about an inspiring personality through a responsive and visually engaging webpage.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive web design
- Biography and introduction section
- Timeline highlighting important achievements
- Inspirational quote section
- Image section
- Multiple background colors
- Different font styles
- Clean and visually engaging layout
