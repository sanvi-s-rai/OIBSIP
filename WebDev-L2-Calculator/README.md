# Calculator

## OIBSIP Web Development & Designing – Level 2

### Project Overview

This project is a functional calculator developed using HTML, CSS, and JavaScript. It provides a clean and responsive calculator interface with basic arithmetic operations.

### Technologies Used

- HTML5
- CSS3
- JavaScript

### Features

- Numbers 0–9
- Decimal input
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Clear button
- Backspace/Delete
- Equals button
- Operator chaining
- Division-by-zero error handling
- Responsive calculator interface
- Button event listeners
