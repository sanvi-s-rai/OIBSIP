# To-Do Web App

## 📌 Overview

This To-Do Web App was created as part of the Oasis Infobyte Web Development & Designing Internship – Level 2.

The application helps users manage their daily tasks by allowing them to add, edit, complete, and delete tasks.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Separate pending and completed tasks
- Display task counts
- Responsive user interface
- Simple and user-friendly design
